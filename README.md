# 📊 IAIP-Sales-Data-Analysis

A Sales Data Analysis project using Python to analyze the Sample Superstore dataset. This project performs data cleaning, exploratory data analysis (EDA), and data visualization to discover sales and profit trends.

---

## 📌 Project Overview

The objective of this project is to analyze sales data and gain insights into:

- Sales performance by category
- Profit by category
- Sales by region
- Profit by region
- Sales by ship mode
- Profit by ship mode
- Top 10 states by sales
- Sales distribution
- Correlation between numerical features

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Key Insights

- Technology generated the highest sales.
- The West region recorded the highest sales and profit.
- Standard Class was the most frequently used shipping mode.
- Sales data is positively skewed, with a few high-value transactions.
- Sales and Profit show a positive correlation.
